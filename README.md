# TechPulse - Technology & AI Blog Website

A complete, SEO-optimized, fully responsive blog website for a UAE-based client, built with modern web technologies and ready for WordPress integration.

## 🚀 Features

- **Modern, Minimalist Design** - Clean tech-inspired layout with professional aesthetics
- **Fully Responsive** - Mobile-first design that works on all screen sizes
- **SEO Optimized** - Proper meta tags, schema markup, Open Graph, and Twitter Cards
- **Dark Mode** - Toggle between light and dark themes with localStorage persistence
- **Fast Performance** - Optimized for Core Web Vitals with lazy loading images
- **Accessible** - WCAG compliant with proper semantic HTML and ARIA labels
- **WordPress Ready** - Clean, modular structure for easy theme conversion

## 📁 Project Structure

```
Blog Site/
├── index.html          # Main landing page
├── single-post.html    # Single blog post template
├── category.html      # Category archive page
├── about.html         # About page
├── contact.html       # Contact page
├── write-for-us.html  # Guest writer submission page
├── css/
│   └── style.css      # Custom styles and Tailwind extensions
└── js/
    └── script.js      # Main JavaScript functionality
```

## 🎨 Design Specifications

- **Color Scheme**: White background, dark gray text (#222), neon blue/emerald green accents
- **Typography**: Poppins (body text), Space Grotesk (headings)
- **Layout**: Grid-based responsive design with consistent spacing

## 🔧 Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (via CDN)

- **Schema.org** - Structured data for SEO
- **Open Graph** - Social media sharing optimization

## 🚀 Getting Started

1. Open `index.html` in a modern web browser
2. All pages are linked and ready to navigate
3. No build process required - works out of the box

## 📱 Responsive Breakpoints

- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

## 🎯 WordPress Integration

The code is structured with modular components that can easily be converted to WordPress:

- Header and footer components are reusable
- Post cards can be converted to WordPress loop templates
- Category filters can use WordPress taxonomies
- Forms can integrate with Contact Form 7 or WPForms
- Newsletter form ready for Mailchimp integration
